# 🤖 ربات هوش مصنوعی بله (Bale AI Bot)

یک ربات چت هوش مصنوعی برای پیام‌رسان **بله**، ساخته‌شده روی **Cloudflare Workers** و **Cloudflare Workers AI** — کاملاً رایگان (در حد سهمیه رایگان کلادفلر) و بدون نیاز به سرور یا هاستینگ جداگانه.

## ✨ قابلیت‌ها

- 💬 **۶ مدل هوش مصنوعی متنی** که کاربر می‌تونه بین‌شون سوییچ کنه:
  | مدل | مناسب برای |
  |---|---|
  | 🟢 GPT-OSS 120B | قوی‌ترین مدل، پاسخ‌های پیچیده |
  | 🔵 Gemma 4 27B | مدل عمومی گوگل |
  | 🟣 Qwen3 30B | پایدار و سریع (پیش‌فرض ربات) |
  | 🟠 Llama 4 Scout | مدل متا |
  | 🔴 DeepSeek R1 | مدل استدلالی (Reasoning) |
  | 🟡 GLM-4.7 Flash | قوی برای کدنویسی |

- 🖼️ **ساخت تصویر با دو کیفیت:**
  - `/image` → ساخت سریع تصویر (مدل Flux)
  - `/imagehd` → ساخت با جزئیات بیشتر ولی کندتر (مدل Stable Diffusion XL)

- 🧠 **حافظه مکالمه** — ربات چند پیام آخر رو به خاطر می‌سپاره تا مکالمه منسجم بمونه (با `/reset` قابل پاک شدنه)

- 🏷️ **نمایش نام مدل** — زیر هر پاسخ، اسم مدلی که جواب داده نوشته میشه

- 🖥️ **صفحه وضعیت گرافیکی** — با باز کردن آدرس ورکر توی مرورگر، یه صفحه با دکمه فعال‌سازی Webhook و لیست مدل‌های فعال می‌بینی

## 📋 دستورات ربات

| دستور | کاربرد |
|---|---|
| `/start` | شروع و نمایش راهنما |
| `/model` | نمایش لیست مدل‌ها برای انتخاب |
| `/reset` | پاک کردن حافظه مکالمه |
| `/image <توضیح>` | ساخت تصویر سریع |
| `/imagehd <توضیح>` | ساخت تصویر باکیفیت‌تر |

## 🛠️ چطور کار می‌کنه؟

این پروژه یه **Cloudflare Worker** واحده که:
1. پیام‌های بله رو از طریق Webhook دریافت می‌کنه
2. با استفاده از باینداینگ **Workers AI** (بدون نیاز به کلید API جدا) به مدل انتخابی کاربر پاسخ می‌گیره
3. تاریخچه مکالمه و مدل انتخابی هر کاربر رو توی یک **KV Namespace** ذخیره می‌کنه
4. جواب رو از طریق API بله (`tapi.bale.ai`) برای کاربر ارسال می‌کنه

## 🚀 راهنمای گام‌به‌گام نصب

### پیش‌نیازها
- یک حساب کاربری [Cloudflare](https://dash.cloudflare.com) (رایگان)
- یک ربات ساخته‌شده در بله از طریق `botfather@`

### مرحله ۱: ساخت ربات در بله
۱. توی اپلیکیشن بله، به `botfather@` پیام بده
۲. با دستور مناسب یه ربات جدید بساز
۳. **توکن ربات** رو که بهت میده، جایی ذخیره کن (بعداً لازمش داری)

### مرحله ۲: ساخت Worker در Cloudflare
۱. وارد [Cloudflare Dashboard](https://dash.cloudflare.com) شو
۲. برو به **Workers & Pages** → **Create** → **Create Worker**
۳. یه اسم بده (مثلاً `bale-ai-bot`) و بسازش
۴. وارد ادیتور کد ورکر شو، کل محتوای فایل `worker.js` این ریپازیتوری رو کپی کن و جایگزین کد پیش‌فرض کن
۵. **Deploy** بزن

### مرحله ۳: ساخت KV Namespace (حافظه ربات)
۱. توی همون ورکر، برو به تب **Bindings** (یا **Settings → Bindings**)
۲. **Add binding** رو بزن → نوع رو **KV Namespace** انتخاب کن
۳. یه Namespace جدید بساز (مثلاً `bale-bot-kv`)
۴. تو قسمت **Variable name** دقیقاً بنویس: `KV`
۵. ذخیره کن

### مرحله ۴: وصل کردن Workers AI
۱. همون تب **Bindings** → **Add binding**
۲. نوع رو **Workers AI** انتخاب کن
۳. تو قسمت **Variable name** دقیقاً بنویس: `AI`
۴. ذخیره کن

### مرحله ۵: تنظیم متغیرهای محیطی
برو به **Settings → Variables and Secrets** و این دو مورد رو اضافه کن:

| نام متغیر | مقدار | نوع |
|---|---|---|
| `BALE_BOT_TOKEN` | توکنی که از `botfather@` گرفتی | **Secret** |
| `WORKER_DOMAIN` | آدرس ورکرت، مثلاً `bale-ai-bot.username.workers.dev` | Text |

> ⚠️ حتماً برای توکن گزینه **Encrypt/Secret** رو بزن.

### مرحله ۶: فعال‌سازی Webhook
۱. بعد از ذخیره تنظیمات، یه بار Deploy رو بزن (اگه قبلاً نزدی)
۲. آدرس ورکرت رو توی مرورگر باز کن: `https://<آدرس-ورکرت>`
۳. یه صفحه با دکمه سبز می‌بینی — روی **«فعال‌سازی Webhook»** بزن
۴. اگه پیام موفقیت (`"ok": true`) دیدی، ربات آماده‌ست 🎉

### مرحله ۷: تست
برو توی بله، ربات رو پیدا کن و `/start` بفرست.

## 🐞 عیب‌یابی

**ربات جواب نمیده؟**
- مطمئن شو مرحله ۶ (فعال‌سازی Webhook) رو انجام دادی
- مطمئن شو `BALE_BOT_TOKEN` رو درست و بدون فاصله اضافه وارد کردی
- برو به تب **Observability → Logs** توی ورکرت و ببین چه خطایی ثبت شده

**یه مدل خاص کار نمی‌کنه؟**
بعضی مدل‌های Workers AI (مخصوصاً مدل‌های «Partner»، مثل مدل‌های خیلی جدید یا Frontier) ممکنه نیاز به سطح دسترسی یا Billing متفاوتی روی اکانت کلادفلر داشته باشن. مدل‌های این پروژه همه از دسته **Cloudflare-hosted** انتخاب شدن تا این مشکل رو نداشته باشن، ولی وضعیت مدل‌ها ممکنه تغییر کنه — می‌تونی مستقیم توی [Workers AI Playground](https://playground.ai.cloudflare.com) مدل مدنظرت رو تست کنی.
